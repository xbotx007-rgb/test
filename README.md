# ProgressVision

ProgressVision — Android-приложение для визуализации личного прогресса в трёх сферах: спорт, задачи и повседневная активность.

## Идея

Приложение помогает человеку видеть, что он действительно движется вперёд, даже если результат кажется незаметным. Любые действия пользователя превращаются в понятные визуальные данные — графики, кольца прогресса и статистику.

## Структура

В приложении три главные вкладки:

- **Спорт** — создание собственных трекеров (подтягивания, жим, бег и т.д.), запись подходов/повторений/веса, графики прогресса за разные периоды.
- **Задача** — большие цели разбиваются на подзадачи, прогресс отображается кольцом, для каждой подзадачи есть таймер.
- **День** — быстрый лог активностей по категориям, дневная и недельная статистика времени.

Время из «Спорт» и «Задача» автоматически попадает в дневной лог.

## Технологии

- Kotlin + Jetpack Compose
- Room (локальное хранилище — local-first, всё офлайн)
- Material 3
- minSdk 24, target/compileSdk 34

## Сборка

```bash
./gradlew :app:assembleDebug
```

APK будет в `app/build/outputs/apk/debug/`.
