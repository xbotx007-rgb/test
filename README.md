# ProgressVision

Android-приложение для визуализации личного прогресса в трёх сферах: спорт, задачи и повседневная активность.

## Основные возможности

- **Спорт** — пользовательские спортивные трекеры (подходы, повторения, вес, время, дистанция) с графиками прогресса за 7 дней, месяц, 3 месяца и всё время.
- **Задача** — большие цели разбиваются на подзадачи. Кольцо прогресса наглядно показывает, сколько уже сделано. Для каждой подзадачи есть таймер.
- **День** — лог активностей по категориям с быстрым стартом таймера и дневной/недельной статистикой.

Все данные хранятся локально (Room), приложение работает офлайн. Тренировки и таймеры подзадач автоматически добавляются в дневную статистику.

## Стек

- Kotlin + Jetpack Compose (Material 3)
- Room (локальная база данных)
- Coroutines / Flow
- ViewModel / Navigation Compose

## Структура

```
app/src/main/java/com/progressvision/app/
├── data/         — Room entities, DAO, репозитории
├── ui/
│   ├── screens/
│   │   ├── sport/  — вкладка «Спорт»
│   │   ├── task/   — вкладка «Задача»
│   │   └── day/    — вкладка «День»
│   ├── components/ — переиспользуемые элементы (кольцо прогресса, мини-график)
│   ├── navigation/
│   └── theme/
└── MainActivity.kt
```

## Сборка

```bash
./gradlew :app:assembleDebug
```

Минимальная версия Android: API 26 (Android 8.0).
